# URL Switcher Pro

URL Switcher Pro 是一个 Chrome 扩展程序，用于在内网和外网 URL 之间快速切换。它可以帮助开发人员在不同的网络环境下自动切换 URL，提高工作效率。

## 功能特性

- 自动 URL 切换：在内网和外网环境下自动切换 URL
- 多配置管理：支持添加多个 URL 映射配置
- 状态检测：实时检查 URL 可访问状态
- 配置导入导出：支持配置的备份和恢复
- 国际化支持：支持中文和英文界面
- 现代化界面：简洁美观的用户界面

## 安装方法

1. 下载本扩展程序
2. 打开 Chrome 浏览器，进入扩展程序页面 (`chrome://extensions/`)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本扩展程序所在目录

## 使用说明

### 基本配置

1. 点击浏览器工具栏中的扩展图标
2. 启用/禁用全局自动切换开关
3. 点击"添加配置"按钮新增 URL 映射
4. 填写配置信息：
   - 配置名称：用于识别不同的配置
   - 内网地址：内网环境下的 URL
   - 外网地址：外网环境下的 URL

### 功能操作

- **检查状态**：点击配置项中的"检查状态"按钮，可以检查 URL 的可访问状态
- **删除配置**：点击配置项中的"删除"按钮，可以删除不需要的配置
- **导出配置**：点击"导出配置"按钮，将所有配置导出为 JSON 文件
- **导入配置**：点击"导入配置"按钮，从 JSON 文件中导入配置

### 状态指示

配置项中的状态指示器颜色含义：
- 绿色：URL 可访问
- 红色：URL 不可访问
- 黄色：正在检查中
